# Code of Conduct

## Our Standard

Contributors to Hooke are expected to communicate respectfully and constructively.

We welcome useful criticism, technical disagreement and different approaches, provided they are discussed professionally.

## Expected Behaviour

- Be respectful and considerate.
- Focus criticism on ideas and implementation, not people.
- Provide useful technical feedback.
- Respect different levels of experience.
- Keep discussions relevant to the project.

## Unacceptable Behaviour

Harassment, discrimination, threats, personal attacks, deliberately disruptive behaviour and inappropriate content are not acceptable.

## Enforcement

Project maintainers may remove comments, reject contributions or restrict participation when behaviour violates this code.
